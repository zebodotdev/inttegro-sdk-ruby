#reactivate ⇒ Boolean? (readonly)

Clears the state that prevents new purchases. For canceled Buy links this removes inactive_at. For expired Buy links this clears an existing elapsed expires_at value. It does not remove the order claim from a used single-use intent.

Optional in the API payload; omitted values default to nil. Wire name: reactivate.
