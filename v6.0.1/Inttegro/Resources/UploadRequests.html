Overview

Client for delegated, policy-constrained file uploads.

Access this resource through Client#upload_requests. Management methods use the client's API key; #fulfill uses the public capability URL and is intentionally unauthenticated.

def fulfill(upload_url:, file:)
  @http.post_multipart_model(
    upload_url,
    Inttegro::Shared::UploadFulfillment,
    files: { file: file },
    authenticated: false,
    operation: "upload_requests.upload"
  )
end
